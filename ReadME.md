# Capstone Project: Secure E-Commerce Web Application Deployment with DevSecOps Practices
# Project Overview

### Objective:
Deploy a highly available, secure, and automated e-commerce web application using DevSecOps principles. This project will simulate a real-world scenario for a tech company launching an online store.

# Tech Organization Scenario:

* Organization : TechShop NG – a mid-sized online retailer in Nigeria expanding its operations globally.

* Problem: The current deployment pipeline is slow, lacks automated security checks, and manual infrastructure provisioning leads to configuration drift.

### Goal:
Implement a DevSecOps pipeline that ensures automated builds, continuous integration and delivery, vulnerability scanning, monitoring, and secure infrastructure provisioning.

# Project Deliverables:

* Web application (frontend + backend + database)

* Infrastructure as Code (IaC) setup

* CI/CD pipeline integrated with security checks

* Automated vulnerability scanning and remediation

* Centralized logging and monitoring

* Incident response plan for potential breaches

# Tech Stack
### Layer	Technology
* Frontend	ReactJS
* Backend	Node.js + Express
* Database	MySQL or PostgreSQL
* Containerization	Docker
* Orchestration	Kubernetes (Minikube for local / EKS for AWS)
* CI/CD	GitHub Actions / GitLab CI / Jenkins
* IaC	Terraform
* Secrets Management	HashiCorp Vault / AWS Secrets Manager
* Security & Scanning	SonarQube, Trivy, OWASP ZAP
* Monitoring & Logging	Prometheus, Grafana, ELK Stack
* Cloud	AWS (VPC, S3, IAM, EC2, RDS, EKS, CloudWatch)
